# Week 4: Predictive Modeling and Optimization in Logistics
A reproducible regression project forecasting shipment delivery time.

## Contents
- `logistics_week4_report.docx`: full assignment report
- `logistics_week4_dataset.csv`: 650 synthetic shipment records
- `logistics_week4_model.py`: preprocessing, Random Forest training, CV, evaluation
- `w4_*.png`: charts used in report

## Run locally
```bash
pip install pandas numpy matplotlib scikit-learn
python logistics_week4_model.py
```
The dataset is synthetic and intended for educational purposes. Metrics are not real-world benchmarks.
