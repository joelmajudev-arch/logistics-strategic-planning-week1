# Logistics Data Analysis — Week 3
This repository contains a simulated logistics dataset, exploratory analysis script, charts, and a DOCX report.

## Contents
- `logistics_analysis_report.docx`: detailed report
- `logistics_sample_dataset.csv`: 500 simulated shipments
- `logistics_analysis.py`: Python analysis and visualization script
- `charts/`: plots generated by the script

## Run
```bash
pip install pandas numpy matplotlib
python logistics_analysis.py
```
**Note:** All records are synthetic and for educational purposes only.
